# RDP Launcher

Программа для запуска файлов **`.rdp`** для сотрудников, у которых есть основной и резервный каналы связи.

## Возможности

- Автоматическая проверка доступности сервера по **IP:PORT**.
- Автоматический запуск рабочего подключения.
- Поддержка нескольких профилей сотрудников.
- Хранение только адресов серверов в `config.ini`.
- Пароли и учетные данные **не сохраняются**.
- Версия для **.NET 8**.
- Отдельная версия со встроенным **.NET 8**, не требующая установки рантайма.

## Принцип работы

При запуске программа:

1. Проверяет доступность основного сервера.
2. Если основной сервер доступен — запускает соответствующий `.rdp`.
3. Если основной недоступен — проверяет резервный.
4. Если резервный доступен — запускает резервный `.rdp`.

## Конфигурация

Настройки хранятся в файле `config.ini`.

### Пример

```ini
[Options]
CloseAfterLaunch=True

[Servers]
MainIP=0.0.0.0
MainPort=3369

BackupIP=0.0.0.0
BackupPort=3369

[Profiles]
Бухгалтер=buh.rdp|buh_rezerv.rdp
Кассир=kassir.rdp|kassir_rezerv.rdp
Менеджер=manager.rdp|manager_rezerv.rdp
```

## Описание параметров

### Раздел `[Варианты]`

| Параметр | Описание |
|----------|----------|
| `CloseAfterLaunch` | Закрывать программу после запуска RDP (`True` / `False`) |

### Раздел `[Серверы]`

| Параметр | Описание |
|----------|----------|
| `MainIP` | IP-адрес основного сервера |
| `MainPort` | Порт основного сервера |
| `BackupIP` | IP-адрес резервного сервера |
| `BackupPort` | Порт резервного сервера |

### Раздел `[Профили]`

Каждая строка имеет формат:

```text
Название=Основной.rdp|Резервный.rdp
```

Например:

```text
Бухгалтер=buh.rdp|buh_rezerv.rdp
```

## Требования

- Windows
- .NET 8 (для обычной версии)

или

- Версия со встроенным .NET 8 (установка рантайма не требуется).

## Безопасность

Программа **не хранит**:

- пароли;
- логины;
- учетные данные Windows.

В файле `config.ini` сохраняются только адреса серверов, номера портов и список профилей.
